# Human Gut Microbiome Atlas (HMP2) Dataset Backup

## Overview

This repository serves as an archival backup of the **Human Gut Microbiome Atlas (HMP2)** CSV dataset that was previously available on Kaggle and is no longer accessible in its original form. The purpose of this repository is to preserve the dataset for research reproducibility, educational use, and long-term availability.

The original dataset was published on Kaggle by **Qasim Hussain** under the title **"Human Gut Microbiome Atlas (HMP2)"** and was based on data from the Human Microbiome Project 2 (HMP2) / Integrative Human Microbiome Project (iHMP) research initiative. 【1-96123d】【2-7c4aa1】

**Original Dataset URL (archived source):**  
https://www.kaggle.com/datasets/qasimhu/human-gut-microbiome-atlas-hmp2/data

## Purpose of This Repository

This repository exists to:

- Preserve a copy of the original CSV dataset after its removal or unavailability from the original source.
- Support reproducible microbiome research and data analysis.
- Provide a stable reference point for projects that previously depended on this dataset.
- Prevent loss of access to publicly shared research data.

## Dataset Origin

The dataset was originally uploaded and distributed by **Qasim Hussain** and describes longitudinal human gut microbiome data derived from the **HMP2 (Integrative Human Microbiome Project)** cohort, focusing on inflammatory bowel disease (IBD), including Crohn's Disease and Ulcerative Colitis. 【2-7c4aa1】【3-084bd4】
